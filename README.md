# 現金・当日券 集計

イベント終了時に、手元の現金と当日券の売上を照合するための Web アプリです。
差額が出たときは、考えられる原因（券の入力ずれ・現金の数え間違い）を候補として表示します。

公開 URL：https://tsun3.github.io/cash-ticket/

## 使い方

1. **現金集計**：金種ごとに枚数を入力します（1万円〜1円）。
   - 「＋」「−」をタップすると1枚ずつ増減します。長押しすると連続で増減します。
   - 数字を直接入力することもできます。
2. **釣り銭準備金**：開始時に用意した釣り銭の額を入力すると、現金合計から差し引いた「売上現金」で照合します。未入力なら差し引きません。
3. **当日券集計**：券種名・単価・販売枚数を入力します。販売枚数も「＋」「−」で増減できます。「＋ 券種を追加」で券種を増やせます。
4. **照合結果**：売上現金と当日券売上合計が一致しているかを表示します。
   - 一致：緑
   - 不一致で、差額に合う候補がある：黄（入力ずれの候補を表示）
   - 不一致で、候補が見つからない：赤

### 入力ずれの候補

- **当日券の入力**：差額に合う券の組み合わせを表示します。現金が不足しているときは、入力した枚数を超える候補は出しません。
- **現金の数え間違い**：1つの金種を数え間違えたと考えると差額に合う候補を表示します（例：1,000円札を1枚少なく数えている）。

### リセット

「リセット」から、消す範囲を選べます。

- **枚数だけリセット**：現金と販売枚数を消し、券種・単価・釣り銭準備金は残します。同じ券種で次の回を集計するときに便利です。
- **すべてリセット**：券種や準備金も含めて、入力をすべて消します。

## 設定の共有（共有URL）

券種・単価・釣り銭準備金を URL にして、スタッフの端末に配れます。

1. 券種・単価・釣り銭準備金を入力する
2. 画面下の「設定の共有」→「URLを作る」
3. 「共有する」または「URLをコピー」で、LINE などに送る

受け取った人が URL を開くと、その設定が読み込まれます。共有 URL は**最初の設定用**で、一度読み込んだあとはアプリがその設定を覚えておきます。

- 何も入力していない端末では、そのまま読み込みます。
- すでに別の入力がある端末では、置き換えてよいか確認します（読み込むと、入力した枚数は消えます）。
- 同じ設定がすでに入っているときは何もしません（集計中の枚数もそのまま残ります）。
- 読み込んだあとは、アドレスバーが元のアプリの URL に戻ります。再読み込みしても読み込み直さず、「ホーム画面に追加」しても共有設定に縛られない普通のアイコンになります。
- 「すべてリセット」したあとに共有設定へ戻したいときは、共有 URL をもう一度開くか、「URLから読み込む」に貼り付けてください。
- 共有 URL には、LINE で開いたときに LINE の中ではなく Safari などのブラウザで開くための指定（`openExternalBrowser=1`）が付いています。

### iPhone のホーム画面のアプリで使うとき

ホーム画面に追加したアプリは、Safari とデータが別になっています。アプリを開いて「URLから読み込む」に共有 URL を貼り付けると、設定が入ります（最初に1回だけ）。

URL の形式（`#` 以降はサーバーに送信されません）：

```
https://tsun3.github.io/cash-ticket/?openExternalBrowser=1#v=1&f=<準備金>&t=<単価>-<券名>&t=<単価>-<券名>
```

## iPhone のホーム画面に追加する

1. Safari でアプリの URL を開く
2. 共有ボタン →「ホーム画面に追加」

ホーム画面から開くと全画面のアプリとして起動します。一度開いた端末では、電波のない場所でも使えます。
新しいバージョンを公開すると、画面下に「新しいバージョンがあります」と表示され、「更新する」で切り替わります（入力内容は残ります）。

## データの取り扱い

- 入力した金額や枚数は自動で保存され、使っている端末のブラウザ（localStorage）の中にだけ残ります。
- アプリが入力内容を外部のサーバーへ送信することはありません。通信するのはアプリ本体を読み込むときだけです。
- 共有 URL に含まれるのは券種・単価・釣り銭準備金だけです。枚数や集計結果は含まれません。
- 開発者を含め、第三者が集計データを見たり利用したりすることはありません。アクセス解析や広告のプログラムも使っていません。
- 「すべてリセット」するか、ブラウザのデータを消去すると、端末からも削除されます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の構成 |
| `style.css` | 見た目（ライト／ダークモード対応） |
| `script.js` | 集計・照合・候補探索、＋／−ボタン、リセット、設定の共有、更新のお知らせ |
| `manifest.webmanifest` | ホーム画面に追加したときのアプリ情報 |
| `sw.js` | オフライン対応（アプリ本体のキャッシュ）と更新の管理 |
| `icons/` | アプリアイコン |

## 更新するときの注意

アプリのファイルを変更したら、**`sw.js` の `CACHE_VERSION` を必ず上げてください**（例：`"v2"` → `"v3"`）。
利用者の端末はキャッシュしたファイルで動いているため、番号を上げないと新しい版が届きません。
番号を上げて公開すると、利用者の画面に「新しいバージョンがあります」と表示されます。
