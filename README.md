# 現金・当日券 集計

イベント終了時に、手元の現金と当日券の売上を照合するための Web アプリです。
差額が出たときは、登録した券種の組み合わせから「どの券を何枚入力し間違えた可能性があるか」を候補として表示します。

## 使い方

1. **現金集計**：金種ごとに枚数を入力します（1万円〜1円）。
2. **当日券集計**：券種名・単価・販売枚数を入力します。「＋ 券種を追加」で券種を増やせます。
3. **照合結果**：現金合計と当日券売上合計が一致しているかを表示します。
   - 一致：緑
   - 不一致で、差額に合う券の組み合わせがある：黄（入力ずれの候補を表示）
   - 不一致で、組み合わせが見つからない：赤

## iPhone のホーム画面に追加する

1. Safari でアプリの URL を開く
2. 共有ボタン →「ホーム画面に追加」

ホーム画面から開くと全画面のアプリとして起動します。一度開いた端末では、電波のない場所でも使えます。

## データの保存について

入力内容は、使っている端末のブラウザ（localStorage）にだけ保存されます。
サーバーや GitHub には送信されず、他の端末や他の人とは共有されません。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の構成 |
| `style.css` | 見た目（ライト／ダークモード対応） |
| `script.js` | 集計・照合・候補探索の処理 |
| `manifest.webmanifest` | ホーム画面に追加したときのアプリ情報 |
| `sw.js` | オフライン対応（アプリ本体のキャッシュ） |
| `icons/` | アプリアイコン |

ファイルを更新したときは、`sw.js` の `CACHE_NAME` の番号を上げてください（例：`cash-ticket-v2`）。
利用者の端末では、次に開いたときに裏で新しい版を取得し、その次に開いたときから反映されます。
